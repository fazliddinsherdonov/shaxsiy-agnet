### 👥 Guruh boshqaruvi

1. Guruh ID ni oling (@getidsbot orqali)
2. /groupadd -1001234567890 Guruh nomi
3. Bot guruhda avtomatik javob beradi

Modlar:
- smart: faqat savollarga javob (tavsiya)
- all: hammaga javob beradi

/groupmode -1001234567890 smart
/groupmode -1001234567890 all
/grouplist  — faol guruhlar
/groupdel -1001234567890  — o'chirish
